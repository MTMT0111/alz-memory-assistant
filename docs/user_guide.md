# 照护助手使用指南

## 第一次使用
1. 打开 http://[你的IP]:8000/login
2. 选择你的名字，输入 PIN 码
3. 在患者列表里找到你的家人，点"进入照护"

## 每天怎么用（5分钟）
- 早上：查看昨晚有没有风险提醒，确认今日用药计划
- 陪老人聊天：点"开始对话"，可以语音说话
- 晚上：点"记录今日"，保存当天的照护日志

## 语音使用（推荐）
- 点麦克风按钮说话，AI 会语音回应
- 如果声音太快/太慢，在设置里可以调整

## 记忆管理
- 系统会自动从对话里提取有意义的记忆
- 照护者需要在"记忆审批"里确认后才会生效
- 去"追忆"页面可以用记忆和老人聊过去的事

## 遇到问题
- AI 说了奇怪的话：忽略即可，不要让老人纠正它
- 语音不工作：检查浏览器是否允许麦克风权限
- 系统很慢：可能是 AI 接口网络问题，等几秒再试
