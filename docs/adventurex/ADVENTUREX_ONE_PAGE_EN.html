Problem. Family dementia care is more than conversation.

Insight. A general-purpose LLM can generate language, but it does not inherently understand real care state, family memory context, or safety boundaries.

Solution. This project proposes a Care Loop + Emotional Memory Companion.

Current Progress. The audited snapshot already includes a working prototype with multi-patient management, DeepSeek chat, caregiver dashboard, familiar materials, photo timeline, memory candidate review, consent flow, TTS fallback, and PWA scaffolding.

Evidence. Internal 10-scenario comparison: baseline 5.60, care system 8.13, improvement +2.53.

Five-Day Goal. Build a clear Hero Demo: From Family Memory to Safer Care.
