# Future Direction: Care Loop + Emotional Memory Companion

> 本项目未来将围绕"日常照护闭环"和"情感记忆陪伴"双主线发展：
> 前者面向家属减负和风险管理，后者面向患者的熟悉感、安全感与情绪支持。

---

## 1. Why This Direction

阿尔兹海默症家庭照护面临两个同样真实的问题：

**家属问题：**
照护者每天需要处理用药提醒、作息管理、风险记录、跨家庭成员协作，
同时承受持续的精神压力。现有工具要么太复杂，要么不懂照护场景。

**患者问题：**
患者的语言和记忆能力在退化，但情感感知能力往往保留更久。
他们需要的不是被测试、被纠正，而是熟悉的面孔、声音和回忆带来的安全感。

普通 LLM 聊天机器人两个问题都解决不了：
它不了解家庭的真实用药和照护记录，也不了解患者的个人历史和情感记忆。

---

## 2. Core Direction A: Care Loop（照护闭环）

**面向对象：** 家属/照护者

**核心价值：** 减轻照护压力，形成可记录、可回溯的日常照护闭环

**关键功能路径：**
照护者录入患者档案和剂量计划

->系统生成每日

照护者确认执行状态

->AI对话中识别风险信号

->风险给照护者生成

每日事件自动记账

->各自端摘要和建议操作

->跨家庭成员协作（多照护者）
**安全原则：**
- 用药事实来自结构化提醒，不让 LLM 猜测或生成用药建议
- 风险事件需照护者手动确认处理
- 记忆素材需照护者审核后才进入患者对话

---

## 3. Core Direction B: Emotional Memory Companion（情感记忆陪伴）

**面向对象：** 患者本人

**核心价值：** 通过熟悉素材建立情感陪伴，不考问、不纠正、不刺激

**关键功能路径：**
照护者上传家庭照片、录制语音留言、录入旧事件

->直接审核记忆素材（敏感内容标记）

->患者端对话引入熟悉素材

->非测试式对话：不问“你还记得吗”，而是“你看，这是...”

->从照片/旧歌/旧地点自然开启回忆

->情绪状态识别（低落/忧/忧/困惑）

->反馈给远端
**对话原则：**
- 温和、低刺激
- 不测试记忆
- 不纠正错误
- 不主动提及已识别为敏感的记忆
- 用熟悉感而非信息量来建立安全感

## 4. How They Connect（两条线如何联动）
[照护者]录入档案、照片、照护

↓

[系统]构建患者的熟悉资料库+照护结构

↓

[患者]与AI进行情感陪伴对话

↓

[系统]识别：情绪状态、记忆线索计划、风险信号

↓

[照护者]接收：每日照护摘要、风险提醒、记忆候选审核

↓

[系统]更新：患者记忆库、照护台账

↓

[患者]获得更多个性化、更多温度的住院对话
两条线不是平行的，而是形成一个闭环：
照护者的输入让患者陪伴更好，患者对话的输出让照护者决策更准。

## 7. Safety Boundary（安全边界）

本系统明确不是医疗设备，以下是必须坚守的安全边界：

| 方面 | 我们做的 | 我们不做的 |
|------|---------|-----------|
| 用药 | 结构化提醒，照护者确认 | LLM 自动判断用药剂量或时机 |
| 记忆 | 家属审核后使用 | 无审核地使用敏感家庭信息 |
| 诊断 | 不提供 | 任何形式的医学诊断或病情判断 |
| 风险 | 识别并推送给照护者 | 自动处置或替代照护者判断 |
| 数据 | 本地存储，最小化 API 传输 | 未经同意上传完整患者信息 |
| 同意 | 知情同意流程 + 签署记录 | 跳过知情同意直接使用 |

**核心原则：** AI 辅助照护，不替代照护。
